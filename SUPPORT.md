# Support

## How to get help

| If you… | Then… |
| --- | --- |
| Found a bug in the canary site | Open a [bug report](https://github.com/danielvm-git/bigbase-canary-go/issues/new?template=bug_report.yaml) |
| Have a question about the release→deploy pipeline | Open a [GitHub Discussion](https://github.com/danielvm-git/bigbase-canary-go/discussions) |
| Want to request a change | Open a [feature request](https://github.com/danielvm-git/bigbase-canary-go/issues/new?template=feature_request.yaml) |
| Found a security vulnerability | Follow [`SECURITY.md`](./SECURITY.md) — **do not** open a public issue |

## Before asking

Please check these first:

1. **[`README.md`](./README.md)** — what this repository is and how it works.
2. **[`AGENTS.md`](./AGENTS.md)** — project context and conventions.
3. **Existing [issues](https://github.com/danielvm-git/bigbase-canary-go/issues)**
   and [discussions](https://github.com/danielvm-git/bigbase-canary-go/discussions)
   — your question may already be answered.
4. **[go.bigbase.click](https://go.bigbase.click)** — the live canary site.

## Response expectations

This is a regression-signal repository maintained on a best-effort basis.
Issues and discussions are reviewed regularly but do not carry an SLA.

## Commercial support

None available. This is an open canary project, not a product.
